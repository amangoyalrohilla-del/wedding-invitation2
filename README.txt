AMAN & PRANJAL — WEDDING INVITATION WEBSITE
============================================

HOW TO EDIT
Open index.html in any text editor and find the block that starts with
"WEDDING DETAILS — EDIT EVERYTHING HERE". Every name, time, line of text,
photo path and calendar entry lives in that one block.

- Grandparents' names: replace the text in square brackets.
- Our story: replace "[Add your story here]".
- Any text inside [square brackets] shows on the site with a dotted
  underline so you can spot what still needs filling in.
- Set any field to "" to hide it.

PHOTOS
Replace files in /images with the same file names (JPG, ~1100px tall is ideal):
  couple-hero.jpg, groom.jpg, bride.jpg, prewedding-01.jpg ... prewedding-06.jpg

MUSIC
Add a licensed track as audio/wedding-song.mp3. Without it, the music
button stays hidden and nothing breaks.

CALENDAR
save-the-date.ics and baraat.ics power the "Apple / iPhone Calendar"
button. If you change the date or time in index.html, update these two
files too (they are plain text).

HOSTING
Upload the whole folder as-is to Netlify (drag and drop), Vercel,
GitHub Pages, Hostinger or any static host. No build step needed.
